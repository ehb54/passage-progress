Passage Progress

See how far you are through a long web page, or through just the passage your group is reading.

Option 1 · best

Chrome extension

Coming soon to the Chrome Web Store. Until then it can be installed from GitHub (uses Chrome's Developer mode).

  • The meter appears on every page automatically.
  • Shows your % on the toolbar icon and at the top of the right-click menu.
  • Right-click a line to mark where the passage starts or ends, or where you stopped.
Option 2 · no install

Bookmarklet

A bookmark that adds the meter to the page you're on. Works in Chrome, Edge, Firefox and Safari.

  1. Show your bookmarks bar: ⌘ ⇧ B on a Mac, Ctrl Shift B on Windows. In Safari: View → Show Favorites Bar.
  2. Drag this button onto the bar:
    Passage Progress or click it to try it on this page
  3. On the page you're reading, click the bookmark. Click it again to hide the meter.

After a page reload, click the bookmark again. Your marks are remembered for each page. A few sites with strict security settings block bookmarklets. The extension works there.

Using it

  • Page % shows how far you've scrolled, with roughly how many screens are left.
  • Mark the passage: hover over the meter, click Set start, then click the first line of the passage. Do the same with Set end on the last line. With the extension you can also right-click a line instead.
  • Passage % is 0% when the start line is at the top of the window, and 100% when the end line reaches the bottom.
  • Go to start jumps back to the passage, and Clear removes the start and end marks.
  • Didn't finish? Click Stopped here, then click the line where you stopped. It leaves a marker with the date and time, like “⏸ Stopped Tue, Nov 11, 3:40 PM”. Next time, Resume scrolls straight back to it. Each meeting can leave its own marker. The newest is bold, older ones are faded, and the × on a marker deletes it.
  • Drag the meter to move it, and double-click it to put it back in the corner. It stays the same size when you zoom in on the page.
